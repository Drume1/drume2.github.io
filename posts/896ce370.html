FTP 流量分析 WriteUp

环境拓扑

角色 IP 备注
攻击者 192.168.39.88 Kali/攻击机
受害服务器 192.168.39.90 Windows (FileZilla FTP)
网关 192.168.39.2 / 192.168.39.254
其他存活主机 192.168.39.1, 192.168.39.89, 192.168.39.91, 192.168.39.92

1. 攻击者 IP

192.168.39.88

tshark -r FTP.pcapng -Y "ftp" -T fields -e ip.src | sort -u
# 192.168.39.88 → FTP 客户端（攻击者）
# 192.168.39.90 → FTP 服务器（受害）

2. 存活探测网段 / 存活主机数

192.168.39.0/24，共 8 台

攻击者从 192.168.39.88 向整个 /24 网段发送 ARP 请求（opcode=1），收到 8 个 ARP 应答（opcode=2）：

192.168.39.1, 192.168.39.2, 192.168.39.254, 192.168.39.88, 192.168.39.89, 192.168.39.90, 192.168.39.91, 192.168.39.92
tshark -r FTP.pcapng -Y "arp.opcode == 2" -T fields -e arp.src.proto_ipv4 | sort -u

3. 受害服务器开放端口

21, 135, 139, 445, 5985

攻击者对 192.168.39.90 进行了 TCP SYN 端口扫描，通过 SYN-ACK 响应确认开放端口：

端口 服务 SYN-ACK 数
21 FTP 63
135 MSRPC 3
139 NetBIOS 3
445 SMB 31
5985 WinRM 9 
tshark -r FTP.pcapng -Y "ip.src==192.168.39.90 && ip.dst==192.168.39.88 && tcp.flags.syn==1 && tcp.flags.ack==1" -T fields -e tcp.srcport | sort -n | uniq -c

4. FTP 服务软件和版本

FileZilla Server 0.9.60 beta

Frame 2639  220  FileZilla Server 中文版 0.9.60 beta
tshark -r FTP.pcapng -Y "ftp.response.code==220" -T fields -e ftp.response.arg | head -1

5. Nmap 匿名登录探测用户名

anonymous

Nmap ftp-anon 脚本探测，密码使用 IEUser@：

Frame 3193  USER  anonymous
Frame 3198  331   Password required for anonymous
Frame 3199  PASS  IEUser@
Frame 3201  530   Login or password incorrect!
tshark -r FTP.pcapng -Y "ftp.request.command==USER" -T fields -e frame.number -e ftp.request.arg | head -1

6. 暴力破解工具

Hydra

特征：4 线程并发，每轮同时发送 4 个 USER ftpuser → 4 个 PASS <password>，响应超时时触发 421 Login time exceeded 后重建连接。

# 查看并发连接模式
tshark -r FTP.pcapng -Y "ftp.request.command==USER && ftp.request.arg==ftpuser" -T fields -e frame.number -e frame.time -e tcp.stream

7. 暴力破解目标用户名 / 成功密码

ftpuser / ftp@2026

Frame 4143  PASS  ftp@2026
Frame 4161  230   Logged on
tshark -r FTP.pcapng -Y "ftp.response.code==230" -T fields -e frame.number -e ftp.response.arg

8. 暴力破解尝试次数和登录失败

30,33

  • 30 = Hydra 字典爆破 ftpuser 的密码数（password → ftp@2026）
  • 33 = 全局 530 登录失败总数（匿名 1 + 手动 ftp 3 + Hydra 29）

11. 下载 PDF 前的传输模式

BINARY

攻击者在目录浏览时使用 TYPE A（ASCII），下载文件前切换为 TYPE I（Binary）：

Frame 5303  TYPE  A       ← 列目录前
Frame 5306  EPSV          ← 被动模式
Frame 5311  LIST          ← 列出文件
  ...
Frame 5451  TYPE  I       ← ★ 切换为 Binary
Frame 5455  EPSV          ← 被动模式
Frame 5460  RETR  薪资明细.pdf
tshark -r FTP.pcapng -Y "ftp.request.command==TYPE" -T fields -e frame.number -e ftp.request.arg
